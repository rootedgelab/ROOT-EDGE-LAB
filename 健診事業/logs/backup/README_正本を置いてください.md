# 正本フォルダ（3ファイル待ち）

このフォルダには、しょーたさんが以下の3ファイルを置いてください。
置かれるまで、監査・営業文・計画書の生成は着手しません（勝手な代用はしません）。

1. `商品設計書.md` — サイト健診の商品内容・価格・納品物の定義
2. `監査正本プロンプト.md` — 一次監査で使う正式なプロンプト
3. `営業文セット.md` — 営業文の型（「B. 新規向けDM」を含むこと）

## 置かれたあとの扱い

- Claudeは作業前に必ず3ファイルの全文を読み、以降のすべての生成物
  （監査・営業文・計画書）の判断基準として扱います。
- 正本の内容を変更するのはしょーたさんだけです。Claudeが修正案を出す場合は
  別ファイル（`{名前}_draft.md`）として提案し、確定はしょーたさんが行います。

※ 3ファイルが揃ったら、このREADMEは削除せず `logs/` の復元ログに記録の上
   `safe_move.py` でこのフォルダの外（logs/backup/）へ移動して構いません。
